# Resties

**Интерактивная мебель для VoxelCore.**

Контент-пак для [VoxelCore](https://github.com/MihailRis/voxelcore), который добавляет стул и диван.

*Примечание: README написано с помощью ИИ.*

---

## Возможности

- Нажмите ПКМ, чтобы сесть, и Shift, чтобы встать
- [RideableAPI](https://github.com/Neveix/voxelcore-rideable-api) - вы можете пересесть на стул, сидя в [лодке](https://github.com/Neveix/primeval-boats), и наоборот

---

## Установка

- VoxelCore >=0.31.4

- Убедитесь, что установлены зависимости:
  - [RideableAPI](https://github.com/Neveix/voxelcore-rideable-api)
  - [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons)

---

## Для игроков

Стулья и диваны пока что нельзя скрафтить.

### Управление

| Клавиша | Действие |
| :--- | :--- |
| `ПКМ` | Сесть |
| `Shift` | Встать |

---

## Для разработчиков

Этот пак построен на основе [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons) (`intcom`) и демонстрирует его готовые настройки стульев в действии.

### Что показывает этот пак

- Как настраивать параметры стула
- Как переопределять поведение по умолчанию через `modules/intcom/seat/`

### Создавайте свою мебель

Вы можете легко добавлять собственные стулья, диваны или любую другую мебель, на которую можно сесть, в свой пак.

Подробнее см. в документации [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons).

### Зависимости

- [Interactive Commons](https://github.com/Neveix/voxelcore-interactive-commons)
